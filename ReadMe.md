# Student Management System

A basic Student Management System with attendance tracking, developed using Node.js, Express.js, JavaScript, HTML/CSS, and MySQL.

## Features

### Student Management
- Add new students
- View student records
- Edit student information
- Delete student records
- Store roll number, name, email, course, and semester

### Attendance Management
- Select a student
- Select a subject
- Select attendance date
- Mark students as Present or Absent
- Save attendance records
- View attendance history

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Node.js
- Express.js
- MySQL
- mysql2
- dotenv
- CORS
